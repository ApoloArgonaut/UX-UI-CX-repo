# UX/UI + CX Portfolio Project

Landing page de caso de estudio para mostrar un proyecto de **UX/UI con impacto en CX**.

## Qué incluye

- Narrativa de problema → proceso → impacto.
- Sección de personas con interacción (tabs).
- Métricas de resultado simuladas para portfolio.
- Diseño responsive listo para GitHub Pages.

## Cómo usarlo localmente

```bash
python3 -m http.server 4173
```

Luego abre `http://localhost:4173`.

## Publicarlo en GitHub Pages

1. Sube este contenido a un repositorio en GitHub.
2. Ve a **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige tu rama principal y carpeta `/ (root)`.
5. Guarda y comparte el enlace público en tu portfolio.
