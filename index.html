Portfolio Case Study

De flujo complejo a experiencia memorable.

Este proyecto transforma un journey UX/UI en una propuesta CX completa: investigación, rediseño de interfaz, validación y resultados con impacto de negocio.

Ver proceso Contrátame

El reto

El flujo original presentaba fricción en múltiples puntos: demasiadas decisiones, lenguaje poco claro y pasos sin feedback. El resultado era abandono, soporte saturado y baja satisfacción.

Problema UX

Alta carga cognitiva y navegación poco intuitiva.

Problema UI

Jerarquía visual inconsistente y CTAs compitiendo entre sí.

Problema CX

Desconexión entre expectativas del usuario y entrega del servicio.

Proceso end-to-end (UX + UI + CX)

01

Research

Entrevistas, auditoría heurística y mapeo de pain points.

02

Síntesis

Personas, jobs-to-be-done y oportunidades priorizadas.

03

Ideación

Flujos simplificados, wireframes y arquitectura de información.

04

Diseño visual

Sistema de componentes, copy orientado a tareas y prototipo hi-fi.

05

Validación

Testing moderado + iteraciones enfocadas en conversión y claridad.

Personas clave

Sofía: necesita claridad para completar el proceso

  • Valora instrucciones simples y feedback inmediato.
  • Abandona cuando encuentra pasos ambiguos.
  • Responde mejor a microcopys orientados a acción.

Mario: busca velocidad y control

  • Quiere completar tareas repetitivas en pocos clics.
  • Necesita historial y estados claros de su solicitud.
  • Valora consistencia visual y atajos.
